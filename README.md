# wegame-launcher
A simple WeGame laucncher for Linux.

用于在 Linux 上运行 WeGame 的简易启动器（包装器），开箱即用。

所有文件都会放在`~/.wegame-launcher`中；缓存文件放在`~/.cache/wegame-launcher`。

如果 WeGame 在使用时卡死，可以用启动器强制退出后重开。

![](./pics/showcase.png)

## 注意事项

- Wegame的小助手覆盖层可能导致窗口异常，如果遇到可以在 `启动游戏` 右侧三个点打开菜单，启动纯净模式。
- 如果遇到窗口问题可以在`wegame-launcher`的设置页面开启 Gamescope 选项。
- 游戏尽量避免以独占全屏模式启动，否则可能出现黑屏之类的窗口异常。
